# Integrated sci-box diagram resources

These resources are imported from `jihe520/sci-box` (`scibox-diagram`) and are used by the
MathModeling Skills `4drawio` stage. They provide four editable Draw.io layouts, content examples,
XML generators, browser preview, export, and static layout checks.

Use the resources as layout machinery only. All visible nodes, labels, arrows, model names, and
numeric conclusions must be replaced or verified against the current modeling project's reports.
The plugin's mathematical-modeling rules remain authoritative: use a paper overview only when it
reduces explanatory load, route complex work through Draw.io MCP, preserve orthogonal connectors,
and check the final insertion size for Chinese sixth-size text readability.

The bundled Tabler Icons are MIT-licensed. Keep `ATTRIBUTION.md` and
`assets/icons/tabler/LICENSE` when using them.
