# 新增一个模板

> 只在"某类图会反复画"时才做模板；一次性的图直接按 `references/authoring.md` 手写 XML 更快。

每个模板 = 一个渲染脚本 + 一份说明 + 一份示例 + 一张预览 + SKILL.md 索引里的一行。照下面的契约做，新模板与已有模板在用法上完全一致（同样的 CLI、同样的容量校验、同样的自检口径）。

## 一、先标定，再画

模板的观感来自几何精度，**不要目测坐标和配色**。从参考图提取的可行做法（`roadmap-5band` 就是这么来的）：

```python
# 1) 盒子：把"非描边"区域连通域化，逐个填洞后取矩形外接框 + 中位填充色
stroke = (lum < 205) | ((sat > 45) & (lum < 235))
lab, n = ndimage.label(~stroke)
for i, sl in enumerate(ndimage.find_objects(lab), 1):
    m = ndimage.binary_fill_holes(lab[sl] == i)      # 填掉文字造成的孔
    if m.sum() / m.size > 0.88: ...                  # 只保留矩形区域

# 2) 边框/分带线：整行整列扫描"笔画覆盖率"，虚线取 40–70% 区间
# 3) 配色：对参考图做颜色普查（量化到 8 级）取占比最高的若干种
```

字号用实测反推：量一行已知字数的像素宽度 ÷ 字数 = 单字宽 ≈ 字号。**不要假设"标题一定比正文大"**——学术模板常是扁平字号。

## 二、渲染脚本契约

放 `scripts/<template_id>.py`，CLI 固定：

```bash
python3 scripts/<template_id>.py content.json -o out.drawio
python3 scripts/<template_id>.py content.json --check      # 只校验不写
```

必须做到：

1. **写文件前逐槽容量校验**，超框直接非零退出并报出具体预算，例如
   `b2_data: "……" 宽 224px > 可用 212px（约 13 个汉字）`。
   字宽模型：CJK/全角 = 字号 px，半角 = 字号/2，行高 ≈ 1.19 × 字号（16 px 字号对应 19 px）。
   可用宽 = 槽宽 − 8。透明文字标签的高度可放宽到 1.4 倍（无边框，溢出不难看）。
2. **数量可变的组用均分**：`slots(a, b, n, gap)` 把区间等分，槽位随数量自动变窄/变矮；
   在文档里写明每组的允许区间，并在脚本里 `sys.exit` 拦截越界。
3. **几何常量集中在文件头**，内容一律来自 JSON，禁止把文案写进脚本。
4. 手动断行用 `"\n"`，同时接受字符串或字符串数组；竖排文字逐字堆叠（字符正立，不要用
   `horizontal=0` 旋转整体）。

## 三、静态检查的四个坑

`scripts/check_layout.py` 会先于渲染兜住几何问题，但有几处画法需要注意，否则会误报。已验证的规避方式（规则详解见 `preflight-rules.md`）：

| 现象 | 原因 | 做法 |
|---|---|---|
| 连接器"穿过"外框/分带 | 只有 **虚线 + 无填充 + >200×100** 的顶点才被判为容器而豁免 | 大虚线框用顶点（`dashbox`），小虚线框改用闭合折线（`dashrect`，边不参与重叠矩阵） |
| 端点"压住"盒子 | 端点正好落在边界上算相交 | 所有连接器端点离盒边 **1 px** |
| 背景色块与子元素重叠 | 填充顶点进入重叠矩阵 | 背景块设 `strokeColor=none`（会被判为 text，豁免重叠规则） |
| 装饰性外框被判碰撞 | 实线矩形是碰撞目标 | 外框拆成折线段，并在被标题条/旗标遮挡处留缺口——这与"线被压在下面"的视觉效果一致 |

检查器刻意不查紧密堆叠的行列间距与"同族尺寸是否对齐"（前者是刻意排版，后者机器判族必然
跨族误报）。所以正常的图应当是 **FAIL 0 / WARN 0**，一旦报警就值得认真看。

## 四、与手写路径的关系

模板渲染脚本本质就是"把手写 XML 的样式串参数化"，样式速查表在 `references/authoring.md`，
两边必须保持一致（同一套配色、同一套字宽模型、同样的端点内缩 1px 约定）。

## 五、交付清单

```
scripts/<template_id>.py
references/<template_id>.md          # 语义 + 槽位字数预算（两节，带目录）
assets/<template_id>/example.json    # 填满的真实示例，不要占位符
assets/<template_id>/preview.png     # drawio -x -f png -s 1 导出的 1:1 渲染
SKILL.md                             # 在模板索引表加一行
```

`references/<template_id>.md` 必须包含：每个字段的**汉字预算**（用脚本算，不要手估）、
数量允许区间、以及"哪些槽位是并列/汇流/对比"的语义约定——语义放错比字数超框严重得多。

## 六、验收

1. 用示例 JSON 渲染，`drawio -x -f png -s 1 --width <画布宽>` 出图，**肉眼逐带核对**；
2. 造一份"每组取边界数量"的压力配置再渲一次，确认版式不散；
3. 若是复刻某张参考图，用像素差分比对（`np.abs(ref-render)` 聚类定位差异区域），
   把残留差异写进说明的"已知近似"一节。
