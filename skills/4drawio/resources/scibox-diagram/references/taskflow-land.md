# 模板 taskflow-land · 横版任务流水线图

若干**任务块**（黑色虚线框 + 框外左上标题），块内是一条处理链，链上每一步下面可以挂"做法细节"面板；块与块之间用粗块箭头串联。横版画布宽固定 1360，高度按内容自动生长。

渲染：`python3 scripts/taskflow_land.py content.json -o out.drawio`（写前逐槽校验中文字宽；`--check` 只校验）。

## 一、什么时候用它

前三个模板都是**竖版三栏**（左阶段 / 中内容 / 右方法），适合"一篇论文的全景"。这个是**横版任务分解**，适合：

- 竞赛题/项目被拆成"任务一…任务四"，每个任务是一条独立的处理链；
- 每一步不只要给名字，还要写清用了什么方法、什么参数、得到什么结论；
- 需要放进 PPT 或横排页面（宽 1360，天然适合 16:9）。

如果内容是"阶段 × 内容 × 方法"的三向对应，用 `framework-3col`；如果是"分阶段执行流程"，用 `stageflow-3col`。

## 二、视觉语言

这套图的质感来自四件事，改内容时别把它们改掉：

- **直角 + 水平渐变**：步骤盒是深蓝紫（`#2c2c56 → #6f6f9e`）水平渐变、直角无圆角；
- **大括号连接**：竖链的步骤盒与右侧面板之间用大括号，而不是箭头；
- **虚线子框**：面板可套黑色或蓝色虚线框，用来圈出"属于同一步的若干做法"；
- **黑底强调**：最终产出用纯黑底白字（`emph: "black"`），全图最多一两处。

## 三、语义约定

- **块的顺序＝任务的推进顺序**，块间箭头表示"上一个任务的产出喂给下一个任务"。并列关系的任务用同一行（`layout: half`）。
- **步骤盒是"做什么"，详情面板是"怎么做/得到什么"**。别把方法细节写进步骤盒标题，也别让详情面板变成第二条流水线。
- `emph: true` 把某一步标成深蓝，用来标记**关键步骤或结论步**——一个块里最多标一处，否则强调失效。
- 详情面板两种形态：整段文字（说明性）或若干小盒（并列要点）。**并列要点才用小盒**，连续叙述别拆成盒子。
- `tone2: true` 把该步的详情面板从紫系换成蓝系，用于区分"另一类处理"（如参考图里时/频/时频三域特征）。同一块里不要超过两种色系。

## 四、顶层字段

```jsonc
{
  "blocks": [
    {"title": "任务一：____ 建模与 ____ 评估",
     "layout": "half",                    // half = 与下一个 half 块并排；省略 = 整行
     "sections": [ { "type": "vchain", … } ]}
  ]
}
```

块数 1–8；连续两个 `half` 自动并排成一行，其余各占整行。块高按内容自动算，同一行两块取较高者对齐。

## 五、三种版式段

**`pipeline`** — 横向 N 步，步间自动加粗块箭头；每步可挂 `detail`。

```jsonc
{"type": "pipeline", "steps": [
  {"text": "数据读取与预处理", "detail": {"rows": [{"full": "读取双通道 ____ 信号"}]}},
  {"text": "多域特征提取", "tone2": true, "detail": {"frame": "blue", "rows": [
     {"table": [["域 ① 统计量", "n₁ 项"], ["域 ② 谱特征", "n₂ 项"]]}]}},
  {"text": "相似性分析", "emph": "blue"},
  {"text": "最终产出", "emph": "black"}
]}
```
步数 3–7。`emph` 取 `"blue"`（蓝色渐变，标关键步）或 `"black"`（黑底白字，标最终产出）；
一块里最多各标一处。`tone2: true` 把该步详情面板换成蓝系。

**`vchain`** — 纵向 N 步（步间向下块箭头），每步右侧可挂 `side` 面板，并自动用**大括号**把
步骤盒和面板连起来（参考图的标志性画法）。

```jsonc
{"type": "vchain", "steps": [
  {"text": "数据预处理", "side": {"frame": "black", "rows": [
     {"cols": ["平滑滤波", "可视化"]}, {"full": "缺失值与异常值处理"}]}}
]}
```
步数 2–6；常与 `layout: half` 搭配放在半宽块里。纵链之后再接一个 `pipeline` 段，
就能得到参考图那种"竖链 + 底部横向三连"的结构。

### detail / side 面板的三种行

面板由若干行组成，可加 `frame`（`"black"` / `"blue"` 虚线外框）：

| 行类型 | 写法 | 效果 |
|---|---|---|
| 并排小盒 | `{"cols": ["A", "B"]}` | N 个深紫渐变小盒并排，白字，适合并列动作 |
| 通栏说明 | `{"full": "文字\n可多行"}` | 一条浅色通栏，适合叙述 |
| 两列对照 | `{"table": [["名称", "内容"], …]}` | 左名称 / 右内容，中间短横线，适合"模型—公式""指标—数量" |

简写：`"detail": "一段文字"` 等价于单个 `full` 行；`{"items": [...]}` 等价于多个 `full` 行并自动加蓝框。

**`pairs`** — 左列若干输入盒（深紫渐变白字）→ 粗箭头 → 右列若干结果盒（浅色多行左对齐）。

```jsonc
{"type": "pairs",
 "left":  ["在线 ____ 状态评估", "多级概率预警机制设计"],
 "right": ["1，当前状态指标\n2，剩余 ____ 预测", "1，n 级预警划分标准\n2，概率预警补充"]}
```
左右数量可不等；右列按各自行数长高并逐个累加。

### 块间圆柱中转标签

两个半宽块并排时，前一块加 `"cylinder": "任务三"`，会在两块之间画一个竖排文字的圆柱 +
指向右块的粗箭头，用来表示"经由某个任务中转"。

## 六、字数预算

字号：块标题 17、步骤盒 14、详情面板 11；行高＝字号+3。下表为常见数量下每行汉字上限，数量变化时以脚本报错为准。

| 槽位 | 宽度 | 预算 |
|---|---|---|
| 块标题 `title` | 整行块 1232 / 半宽块 588 | ≤35 / ≤17 汉字 |
| `pipeline` 步骤盒 | 6 步时 175 | ≤11 汉字 |
| `pipeline` 详情（整段）| 6 步时 175 | ≤15 汉字/行，行数不限 |
| `pipeline` 详情（小盒）| 6 步时 159 | ≤13 汉字/行 |
| `vchain` 步骤盒 | 半宽块 176 | ≤11 汉字 |
| `vchain` side 面板 | 半宽块 372 | ≤32 汉字/行 |
| `pairs` 左列 | 半宽块 212 | ≤14 汉字 |
| `pairs` 右列 | 半宽块 288 | ≤25 汉字/行 |

半宽块的可用宽度约为整行块的一半，同样的段型在半宽块里预算要砍半。
