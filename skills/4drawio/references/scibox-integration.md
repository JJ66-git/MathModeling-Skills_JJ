# sci-box 示意图整合参考

本参考提炼自 `jihe520/sci-box` 的 `scibox-diagram` 思路，用于数学建模论文的 Draw.io 版式选择；它是布局参考，不是数据或结论来源。

## 版式选择

| 版式 | 适合场景 | 数学建模映射 |
| --- | --- | --- |
| 五带技术路线 | 从题目到结论的纵向链路 | 题意与假设 → 数据与指标 → 模型与算法 → 结果对比 → 评价与推广 |
| 三栏研究框架 | 阶段、研究内容、方法并列 | 子问题/阶段 → 关键变量与任务 → 模型、算法、验证 |
| 三栏阶段流程 | 执行顺序和决策分支 | 数据准备 → 分题求解 → 反馈修正/方案输出 |
| 横版任务流水线 | 16:9 答辩图或多问题总览 | 问题一 → 问题二 → 问题三 → 综合决策 |

## 数学建模约束

1. 每个节点必须能追溯到题干、数据报告、模型说明或实验记录；不确定内容标记为待核验。
2. 先确定列基线、泳道和节点尺寸，再画连接器。默认使用正交折线；分支和汇流使用共享母线，避免扇形斜线。
3. 总览图至少覆盖题目输入、数据处理、每个子问题、模型/算法、验证和决策输出；重要算法根据解释负荷配置流程图、概念/机制图或两者，避免冗余。
4. 颜色只表达语义（数据、模型、验证、输出等），全篇保持同一语义色；装饰元素不能抢过信息层级。
5. 以论文实际插入尺寸检查中文六号（约 7.5 pt）字号、文字溢出、节点/连线重叠和裁切；矢量优先，位图以最终阅读清晰度为准。
